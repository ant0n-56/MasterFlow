# Руководство пользователя МастерFlow 0.1.1

МастерFlow помогает частному мастеру хранить карточки клиентов, планировать сеансы, готовить напоминания и анализировать обратную связь.

Основные функции работают на вашем компьютере. Для них не нужен аккаунт МастерFlow.

## 1. Что требуется

- 64-разрядная Windows 10 версии 2004 или новее либо Windows 11.
- Около 200 МБ свободного места.
- Интернет только для Avito и дополнительного анализа OpenAI.
- Microsoft Edge WebView2 Runtime для запасного импорта со страницы Avito. На большинстве современных компьютеров он уже установлен.

Отдельно устанавливать .NET не нужно: необходимые компоненты входят в MSI и portable-версию.

## 2. Загрузка и запуск

1. Откройте страницу [последнего выпуска МастерFlow](https://github.com/ant0n-56/MasterFlow/releases/latest).
2. Для обычной установки загрузите `MasterFlow-0.1.1-win-x64.msi`, запустите файл и следуйте шагам установщика.
3. Для запуска без установки загрузите `MasterFlow-0.1.1-win-x64-portable.zip`, распакуйте архив в отдельную папку и запустите `MasterFlow.exe`.

**Важно:** файлы версии 0.1.1 пока не имеют цифровой подписи. Поэтому Windows может показать «Неизвестный издатель» или предупреждение Microsoft Defender SmartScreen. Продолжайте только в том случае, если файл загружен со страницы выпуска репозитория `ant0n-56/MasterFlow` и его SHA-256 совпадает с контрольной суммой в описании выпуска.

Контрольная сумма SHA-256 позволяет убедиться, что файл не был изменён. Её можно проверить в PowerShell командой:

```powershell
Get-FileHash -Algorithm SHA256 .\MasterFlow-0.1.1-win-x64.msi
```

Сравните значение в столбце `Hash` с SHA-256 в описании выпуска. Если значения различаются, не запускайте файл и удалите его.

## 3. Навигация и доступность

Слева находится дерево «Разделы программы». В нём есть:

- «Сегодня»;
- «Клиенты»;
- «Расписание»;
- «Обратная связь», внутри — «Отзывы Avito» и «Анализ переписки»;
- «Настройки».

Дерево, кнопки, поля, списки и диалоги имеют доступные имена для программ чтения с экрана. Все основные действия доступны клавиатурой.

- Нажимайте `Tab` и `Shift+Tab`, чтобы переходить между элементами.
- Используйте стрелки в дереве и списках.
- Нажимайте `Enter` или `Пробел`, чтобы выполнить выбранное действие.
- В разделе «Настройки» можно выбрать размер текста от 100 до 200 процентов.

Специальные горячие клавиши запоминать не требуется.

## 4. Первая запись клиента

1. Откройте раздел «Расписание» или нажмите «Создать запись» в разделе «Сегодня».
2. Укажите имя и контакт клиента.
3. Введите название услуги.
4. Выберите дату и укажите время в формате `15:30`.
5. Выберите, когда нужно напомнить клиенту: за 30 минут, 1 час, 2 часа или 1 день.
6. При необходимости добавьте заметку.
7. Нажмите «Сохранить запись».

Клиент автоматически появится в разделе «Клиенты». Там можно изменить карточку, посмотреть историю, создать следующую запись или удалить клиента вместе с его записями.

## 5. Напоминания

В разделе «Сегодня» показаны ближайшие записи и напоминания.

1. Выберите нужное напоминание.
2. Нажмите «Скопировать текст напоминания».
3. Вставьте текст в удобный чат и отправьте клиенту.
4. Вернитесь в МастерFlow и нажмите «Отметить как отправленное».

Если отметка поставлена по ошибке, нажмите «Вернуть в ожидающие». Версия 0.1.1 не отправляет сообщения клиентам автоматически.

## 6. Отзывы Avito через официальный API

Этот способ получает точные оценки и все доступные активные отзывы.

1. Создайте приложение на [портале разработчика Avito](https://developers.avito.ru/).
2. Убедитесь, что приложению доступен API «Рейтинги и отзывы». Доступ зависит от условий и тарифа Avito.
3. В МастерFlow откройте «Настройки».
4. Вставьте Client ID и Client Secret.
5. Нажмите «Сохранить данные Avito».
6. Откройте «Отзывы Avito».
7. Нажмите «Получить отзывы через официальный API».

Client ID и Client Secret защищаются средствами Windows для вашей учётной записи. Программа не показывает их после сохранения. Временный токен Avito не сохраняется.

## 7. Запасной импорт отзывов Avito

Используйте его, если официальный API недоступен вашему аккаунту.

1. Откройте раздел «Отзывы Avito».
2. Вставьте HTTPS-ссылку на своё объявление или профиль Avito.
3. Нажмите «Открыть для импорта».
4. Самостоятельно войдите в аккаунт или пройдите проверку Avito, если она появилась.
5. Откройте окно со списком отзывов. Импорт начнётся автоматически.
6. После импорта запустите локальный анализ.

Кнопка «Удалить данные браузера» удаляет вход, cookies и историю встроенной сессии Avito.

Если нужно только открыть объявление или профиль без импорта, нажмите «Открыть в браузере». Ссылка откроется в обычном браузере Windows и не зависит от встроенного WebView2.

## 8. Анализ переписки

Переписку можно вставить, открыть из TXT-файла или распознать на скриншотах.

1. Откройте «Обратная связь» → «Анализ переписки».
2. Добавьте текст одним из доступных способов.
3. Проверьте текст и удалите ненужные персональные или медицинские сведения.
4. Подтвердите согласие на локальную обработку.
5. Запустите анализ.

МастерFlow покажет вопросы без ответа и рекомендации по общению и объявлению. Исходная переписка и результаты не записываются в базу. Кнопка «Очистить переписку» удаляет их из окна программы.

## 9. Необязательный анализ OpenAI

Локальный анализ работает без OpenAI. Облачный анализ расходует средства вашего собственного аккаунта OpenAI API.

1. Создайте ключ в аккаунте OpenAI API.
2. Откройте «Настройки» и сохраните ключ.
3. В разделе анализа переписки нажмите «Подготовить текст для ИИ».
4. Проверьте точный текст отправки. Программа скрывает явные телефоны, email и ссылки, но вы должны удалить остальные лишние сведения самостоятельно.
5. Подтвердите согласие под подготовленным текстом.
6. Нажмите «Получить рекомендации ИИ».

Ключ защищается средствами Windows и не показывается после сохранения. Кнопка «Удалить ключ API» удаляет его с компьютера.

## 10. Где хранятся данные

Карточки клиентов, записи и статусы напоминаний хранятся локально в профиле текущего пользователя Windows. Рабочий файл и резервная копия защищены Windows. Они не подходят для переноса в другую учётную запись или на другой компьютер.

Отзывы, переписки, скриншоты и результаты анализа автоматически в базу не записываются.

Подробности находятся в [PRIVACY.md](PRIVACY.md).

## 11. Обновление и удаление

Чтобы обновить установленную программу, загрузите новый MSI из раздела Releases и запустите его. Для обновления portable-версии распакуйте новый ZIP в отдельную папку. Перед обновлением закройте МастерFlow.

Удалить программу можно через «Параметры Windows» → «Приложения» → «Установленные приложения» → «МастерFlow» → «Удалить».

Удаление программы может не удалить рабочие данные пользователя. Перед передачей компьютера другому человеку удалите клиентов в программе, данные Avito, ключ OpenAI и данные встроенного браузера.
