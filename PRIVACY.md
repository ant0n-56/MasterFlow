# Данные в МастерFlow

МастерFlow хранит только данные, которые нужны мастеру для работы. Основная обработка выполняется на компьютере пользователя.

## Клиенты и записи

- Карточки клиентов, записи и статусы напоминаний сохраняются локально.
- Файл и резервная копия защищены средствами Windows для текущей учётной записи.
- Клиента и связанные записи можно удалить из карточки клиента.

## Отзывы Avito

- Страница Avito открывается во встроенной браузерной сессии.
- Вход, cookies и история относятся только к этой сессии МастерFlow.
- Кнопка «Удалить данные браузера» удаляет данные этой сессии и выполняет выход.
- Импортированные отзывы и результаты анализа сейчас хранятся только до закрытия программы.

## Переписки и скриншоты

- Текст можно вставить вручную, открыть из файла TXT или распознать на скриншотах.
- Скриншоты распознаются системным OCR Windows на компьютере пользователя.
- Переписка, изображения и результаты анализа не отправляются в интернет и не записываются в базу МастерFlow.
- Кнопка «Очистить переписку» удаляет текст и результаты из программы. Закрытие программы также очищает их.
- Перед анализом нужно проверить текст, убрать лишние персональные и медицинские сведения и явно подтвердить локальную обработку.

## Необязательный анализ OpenAI

- Локальный анализ работает без OpenAI, ключа API и отправки данных.
- Для дополнительного анализа пользователь сохраняет собственный ключ OpenAI API. Ключ защищается для текущей учётной записи Windows и не показывается после сохранения.
- Программа создаёт отдельный предпросмотр и автоматически заменяет явные телефоны, email и ссылки. Пользователь обязан проверить и при необходимости отредактировать весь предпросмотр.
- Отправка начинается только после отдельного согласия под точным текстом предпросмотра.
- В запросе к Responses API задано `store: false`. Обработка данных у поставщика API всё равно регулируется условиями и политиками OpenAI для API.
- Кнопка «Удалить ключ API» удаляет защищённый ключ с компьютера и отключает облачный анализ.

## Ответственность пользователя

Используйте только данные, которые вы вправе обрабатывать. Не добавляйте сведения, которые не нужны для работы с клиентом.
