# МастерFlow

**МастерFlow** — цифровой помощник для частных мастеров, который помогает вести клиентов, управлять записями, возвращать клиентов на повторные сеансы и улучшать качество услуг на основе обратной связи.

## Идея продукта

Клиенты находят мастера на площадках объявлений, записываются на услугу и общаются в разных каналах. МастерFlow объединяет дальнейшую работу в одном месте:

- карточки клиентов и история посещений;
- расписание и напоминания о сеансах;
- повторная запись и возвращение клиентов;
- сбор и анализ отзывов;
- анализ переписок и скриншотов;
- рекомендации по улучшению услуги и объявления.

На странице [последнего выпуска](https://github.com/ant0n-56/MasterFlow/releases/latest) доступны два варианта: MSI для обычной установки и portable ZIP для запуска без установки. Подробное руководство без технических терминов находится в [USER_GUIDE.md](USER_GUIDE.md).

## Подключение официального Avito API

1. Создайте приложение на [портале разработчика Avito](https://developers.avito.ru/).
2. Проверьте, что приложению доступен API [«Рейтинги и отзывы»](https://developers.avito.ru/api-catalog/ratings/documentation). Для пользовательской авторизации область чтения называется `ratings:read`; доступ также может зависеть от тарифа и условий Avito.
3. В МастерFlow откройте раздел «Настройки», вставьте Client ID и Client Secret и нажмите «Сохранить данные Avito».
4. Откройте «Отзывы Avito» и нажмите «Получить отзывы через официальный API».

МастерFlow получает временный токен через официальный адрес `api.avito.ru`, не сохраняет его и загружает отзывы постранично. Если API недоступен для аккаунта, остаётся запасной импорт из открытой пользователем страницы Avito.

Правила обработки локальных данных описаны в [PRIVACY.md](PRIVACY.md).
Команды полной проверки и локальной сборки MSI и portable ZIP описаны в [BUILDING.md](BUILDING.md).
