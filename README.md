# МастерFlow

**МастерFlow** — цифровой помощник для частных мастеров, который помогает вести клиентов, управлять записями, возвращать клиентов на повторные сеансы и улучшать качество услуг на основе обратной связи.

## Идея продукта

Клиенты находят мастера на площадках объявлений, записываются на услугу и общаются в разных каналах. МастерFlow объединяет дальнейшую работу в одном месте:

- карточки клиентов и история посещений;
- расписание и напоминания о сеансах;
- повторная запись и возвращение клиентов;
- сбор и анализ отзывов;
- анализ переписок и скриншотов;
- рекомендации по улучшению услуги и объявления.

## Статус

Разрабатывается первая настольная версия для Windows 10 и 11.

Первый рабочий компонент уже включает:

- нативное главное окно Windows;
- доступное дерево разделов;
- форму создания клиента и записи на сеанс;
- защищённое локальное сохранение клиентов и записей для текущей учётной записи Windows;
- поиск, редактирование и удаление карточки клиента;
- историю и будущие записи выбранного клиента;
- резервную копию локальных данных и восстановление после повреждения файла;
- проверку обязательных данных и занятого времени;
- расчёт времени и контроль срока напоминания;
- готовый текст напоминания с копированием в выбранный мастером чат;
- отметку отправки с возможностью исправить ошибочную отметку;
- создание следующей записи из карточки постоянного клиента;
- вход в Avito через отдельную локальную браузерную сессию;
- автоматический импорт и очистку открытых отзывов Avito;
- локальный анализ сильных сторон, возможных проблем и следующих действий;
- анализ без отправки отзывов во внешние сервисы;
- вставку и импорт текстовых переписок без автоматического сохранения;
- локальное распознавание текста на скриншотах средствами Windows;
- рекомендации по ответам клиенту и содержанию объявления;
- явное согласие перед анализом и полную очистку переписки одной кнопкой;
- понятные сообщения для программ чтения с экрана;
- автоматические тесты бизнес-логики и контракта доступности.

Технологическая основа: .NET 8 и WPF.

Правила обработки локальных данных описаны в [PRIVACY.md](PRIVACY.md).
